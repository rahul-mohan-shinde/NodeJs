## 2. Is list ko kaise follow karna hai?

Har task ke liye ye sequence follow karna hai:

1. Problem: Kya solve kar rahe hain?

2. Logic: Solution kaise kaam karega?

3. Required concepts: Upar diye concepts mein se kaunse seekhne hain?

4. Implementation: Chhota working code banao.

5. Testing: Expected output mil raha hai ya nahi?

6. Independent practice: Code band karke khud implement karo.

7. Interview: Concept explain karo aur questions solve karo.

Agar koi concept pehle se aata hai, usko revise karke aage badh sakte ho. Har task mein har concept ko zero se dobara padhna zaroori nahi hai.

## 3. Do important architecture decisions

* SQL aur MongoDB: Dono seekhenge, lekin unhe zabardasti har jagah use nahi karenge. Ek primary database choose karke chat ko complete karenge; phir doosre database mein equivalent feature implement karke differences samjhenge.

* REST, GraphQL, WebSocket aur gRPC: REST normal request/response ke liye, GraphQL flexible data queries ke liye, WebSocket live chat ke liye aur gRPC internal service communication ke liye use karenge. Ye ek-doosre ke direct replacements nahi hain.

Ek practical clarification: 100 tasks ka matlab 100 study sessions nahi hai. Kuch tasks jaldi honge, kuch debugging aur practice ke kaaran kai sessions lenge.
