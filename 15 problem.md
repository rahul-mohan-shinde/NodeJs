## For every problem, complete these 10 steps

1. Understand the business problem.
2. Write the brute-force solution.
3. Analyze its time complexity.
4. Find the bottleneck.
5. Design the optimal algorithm.
6. Write the pseudocode.
7. Implement it in Java.
8. Test with edge cases.
9. Explain why it's correct.
10. Analyze Time & Space Complexity.

## A challenge for you

Don't use ChatGPT to write the code first.

For each problem:

* Write the algorithm yourself.
* Draw the flow on paper.
* Predict the complexity.
* Implement it.
* Debug it.
* Only then compare your solution with the optimal one.

If you complete all **15 engineering problems** this way, you'll gain much stronger algorithmic thinking than someone who has solved hundreds of questions by memorizing solutions.
